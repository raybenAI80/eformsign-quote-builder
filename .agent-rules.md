# Agent Rules for eformsign Quote Builder

- Keep changes scoped to the task.
- Preserve existing Korean copy, PDF layout, and branding assets unless the task says otherwise.
- Do not edit `.env` or `.env.local`.
- Do not delete or rewrite anything under `backup_*` unless explicitly asked.
- Run `npm run build` before closing a task.
- When changing logic in `src/hooks` or `src/utils`, also run `npx vitest run`.
- Call out any config or documentation changes in the final handoff.
