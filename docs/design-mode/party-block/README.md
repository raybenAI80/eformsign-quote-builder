# 공급사 / 고객사 / 영업 담당자 블록 수정 시안

의견: 이 블록이 다른 영역과 잘 구분되지 않는다 (2026-10-29).
대상: `src/components/preview/QuotePreviewD.tsx` 의 `.qd-three`, `quotePreviewD.css` 165~202줄.

## 진단

1. 블록의 선 문법이 아래 품목 표와 같다. 흰 바탕에 1px `#CCC` 가로선과 세로 구분선뿐이고, 품목 표 행선(1px `#CCC`)·푸터선도 같은 선이다. 블록과 표가 같은 종류의 영역으로 읽힌다.
2. 블록 위쪽에 경계가 없다. 제목줄이 2px 네이비 선으로 끝난 뒤 22px 여백이 있고, 블록은 선 없이 시작한다. 아래쪽 경계(1px 회색)는 다음에 나오는 표 머리의 2px 네이비 선에 눌린다.
3. 크기·굵기 위계가 약하다. 라벨은 12px 네이비로 표 머리(12px 네이비)와 같고, 이름은 17px **Regular** 라 구분 신호가 못 된다. PDF 에서 0.69배로 줄면 1px 선은 약 0.7px, 세로선은 거의 사라진다.

## 시안 (캡처: `current.png`, `v1.png`~`v4.png` = 1123px 실제 크기, `sheet-scaled.png` = 0.69배 비교)

색은 현재 D 팔레트(네이비 `#0B3C66`, `#CCC`, `#555`)와 가이드 팩 색(Light Blue `#F2F9FF`, Light Gray `#F4F4F4`)만 쓴다. 자간·세로쓰기·미디어쿼리 없음.

| # | 이름 | 한 줄 설명 | 장점 | PDF 0.69배 후 위험 |
|---|---|---|---|---|
| 1 | 옅은 배경 카드 | 세 칸을 12~14px 간격으로 떼어 `#F2F9FF` 카드 + 1px `#CCC` 테두리 + 위 4px 네이비 | 변경이 작다. 기존 문법(네이비 선)을 유지하면서 칸이 덩어리로 보인다 | 틴트 `#F2F9FF` 는 거의 흰색이다. 구분은 4px 네이비 윗선(약 2.8px)과 테두리가 맡는다. 틴트 자체는 보조 |
| 2 | 표 머리 띠 | 칸마다 네이비 띠(흰 글자) + 네이비 1px 테두리 박스. 문서 양식 | 구분이 가장 확실하다. 공문서·양식 느낌이라 비즈니스형과 맞는다 | 거의 없다. 네이비 띠는 축소 후에도 진하다. 띠 안 흰 글자 13px 은 약 9px — 읽힌다. 이 구역만 무겁다 |
| 3 | 단일 박스 + 섹션 제목 | `#F4F4F4` 패널 하나, 왼쪽 6px 네이비 띠, “거래 정보” 제목줄, 칸 사이 1px `#CCC` | 한 덩어리로 묶여 “이 문서의 당사자 정보” 라는 의미가 생긴다 | 회색 `#F4F4F4` 는 축소 후 옅다. 구분은 왼쪽 6px 띠(약 4px)와 테두리가 맡는다. 칸 사이 1px 선은 약해진다. 높이 +50px 로 가장 크다 |
| 4 | 위계 재배치 | 고객사(수신처)를 첫 칸·네이비 바탕(흰 글자)으로, 공급사·담당자는 `#F4F4F4` 보조 카드 | 시선이 수신처로 먼저 간다. 구분과 위계가 함께 생긴다 | 흰 글자 13px 이 줄면 약 9px. 읽히지만 이메일 줄이 가장 작다. 인쇄 시 잉크가 많이 든다. 칸 순서가 바뀐다(공급사 → 고객사 → 담당자 순서를 쓰던 사용자에게 변화) |

권장: 시안 2(구분 확실·위험 최소) 또는 시안 4(위계까지 원할 때). 시안 1 은 가장 안전하지만 구분 개선이 가장 작다.
